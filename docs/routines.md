# Routine の登録

Routine の登録は人間が Claude アプリでやる (Claude からはリポジトリを指定して Routine を作れない)。
本文は 1 行だけにする。手順の本体はこのリポジトリの `.claude/skills/` にあり、PR で改善するので、Routine は一度登録したら触らない。

| 名前 | 本文 | 間隔 | セッション |
| --- | --- | --- | --- |
| `<repo> ワーカー` | `/work-issue` | 2 時間おき (`0 */2 * * *`) | 毎回新しいセッション |
| `<repo> 庭師` | `/gardening` | 週 1 回 月曜 06:10 JST (`CRON_TZ=Asia/Tokyo 10 6 * * 1`) | 毎回新しいセッション |

## 登録手順

1. Claude アプリ → Code → Routines → 新規作成
2. リポジトリにこのリポジトリを選ぶ。環境はいつものクラウド環境
3. 本文に上の 1 行を貼る
4. スケジュールを設定する。Routine の最短間隔は 1 時間
5. 「毎回新しいセッションで実行」にする (前回の文脈を引きずらない)

## 動かし方の目安

- ワーカーは 1 回の起動で Issue を 1 件だけ扱う。Issue が溜まっていれば 2 時間に 1 件ずつ減る。急ぐときは対話セッションで `/work-issue` を直接呼ぶ。
- PR を作ったセッションはマージまで生き続け、CI とレビューのイベントで動く。2 時間後の次の起動は別の Issue を拾う。同時に進むのは最大 2 件。
- ワーカーが止まっているように見えたら、`in-progress` の Issue のコメントを見る。庭師が週 1 回、放置されたものを `ready` に戻す。
